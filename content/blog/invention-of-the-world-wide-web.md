# The Invention of the World Wide Web

In March 1989, Tim Berners-Lee, a British computer scientist working at CERN, circulated a proposal called "Information Management: A Proposal." His managers found it vague but exciting. It described a web of hypertext documents that could be read and edited across the laboratory's network — and it became the foundation of the World Wide Web.

## The problem the Web solved

CERN in the late 1980s was full of information, scattered across incompatible computers. Documents lived on mainframes, minicomputers, and workstations, each with its own software, and finding a colleague's notes often meant asking the colleague in person. Berners-Lee wanted information to flow freely between machines instead of being trapped on them.

## One person built the first Web

By the end of 1990, Berners-Lee had built the core of the Web on a NeXT computer: the first web server, the first web browser (which was also an editor), the Hypertext Transfer Protocol for requesting documents, the Hypertext Markup Language for writing them, and the first web pages. The first site, describing the project itself, went live on 20 December 1990. In August 1991, Berners-Lee announced the project on public newsgroups, inviting anyone to join.

## Why it grew

The Web succeeded where other hypertext systems failed because it was simple, open, and free. Anyone could run a server or write a browser without asking permission. In 1993, CERN released the web software into the public domain, and the same year the Mosaic browser brought images and clickable links to ordinary desktop computers. The Web grew from a handful of sites to millions within a few years.

Berners-Lee never patented the Web. He later founded the World Wide Web Consortium to steward its standards, arguing that the Web's universality — working the same for everyone — was its most important feature.

Without that decision to keep it open, the Web might have remained another proprietary system that only one company's computers could read.
